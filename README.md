# Study Planner Student MindAxis

MindAxis is a web site to help students plan their studies, organize daily tasks, create schedules and monitor their academic progress. It also includes an AI assistant to help students with their study questions.

Technologies Used:- React.js, CSS, HTML, JavaScript
- Node.js and ExpressJS
- MongoDB
- Groq API

Key Features:
- Login and Sign Up for Students
- Study Schedule- Daily Duties Management
- AI Study Partner
- Monitor your study progress

Objectives: 
To help students to easily manage their studies and save time.

Main Features:

- Login and Registration: Students can create an account and log in.
- Dashboard: Shows important study information in one place.
- Study Timetable: Students can create and manage their study schedules.
- Task Management: Students can add, update, and delete daily tasks.
- AI Assistant: Helps students get answers to their study-related questions.
- Progress Tracking: Helps students check their completed tasks and study progress.
- Blog and Help Center: Provides useful information and guidance to students.
